# Бегло — правила проекта

Веб-приложение (PWA) для быстрого чтения книг по одному слову. Владелец не программист: всё, что он видит, — по-русски и простыми словами.

## Как работать
- Одна задача — одна ветка — один PR. В `main` сливает только владелец.
- Перед PR: `npm test` и `npm run build` без ошибок. Новая логика — с тестом в `test/`.
- Не добавлять сервер, сбор персональных данных, аналитику и внешние запросы без решения владельца (см. описание первой версии).
- Секреты и личные данные не попадают в код, коммиты и PR.

## Устройство
- `src/rsvp.js` — деление на слова, опорная буква, паузы, таймер. Без DOM.
- `src/parsers.js` — FB2, FB2 в zip, EPUB без защиты, TXT (UTF-8 / Windows-1251).
- `src/books.js`, `src/db.js` — каталог, IndexedDB, недавние книги.
- `src/screens/` — экраны «Библиотека», «Чтение», «Скорость». Маршруты: `#library`, `#read-<id>`, `#speed`.
- `public/classics/` — классика (общественное достояние), собирается `scripts/build_classics.mjs`.

## Дизайн
Бежевый фон `#F4EBDD`, текст `#1A1714`, опорная буква `#B3261E`. Книжный шрифт PT Serif (слова, названия, заголовки), интерфейс — Inter. Шрифты встроены, без внешних загрузок. Касаемые элементы не меньше 44 px.
